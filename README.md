# Schema Checker - Python

This is a simple Schema Checker made in Python, use for checking Schema for UIGF

Supported Schema: 
- UIGF 3.0 (Genshin Impact)
- UIGF 4.2 (All HoYo Games)
- SRGF 1.0 (Star Rail)
- UIGF 4.2a (All Games, unofficial)*

* UIGF 4.2a only adds the new "Anniversary Banners" for ZZZ that the current v4.2 is missing.
